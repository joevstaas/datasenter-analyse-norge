# Første kartdemo – gjennomføring 2026-10-05

Brukeren har godkjent førsteversjonen med Next.js, Mapbox og ODP, norsk prosjektliste, fem tematiske paneler, datert kildevisning, verneområder som kontekst og synlig KI-/demomerking. Først verifisert Vercel-preview. Gateway/publisering på oceandatajo.com håndteres etter preview.

ODP-tabellene leses kun på serveren. Den versjonerte katalogens radantall kontrolleres før visning; ufullstendige svar eller endret utgivelse gir eksplisitt feil. Ingen lokal forskningskopi brukes som skjult fallback. ODP-nøkkelen er hemmelig, Mapbox pk-token offentlig. Geometritabellen brukes ikke fordi plan-CRS er ubekreftet. Miljødirektoratets karttjeneste brukes som rasterlag uten overlappsberegninger.

Arbeid: normaliser tabellrader og kildereferanser; bygg kart/liste/panel; test filtre, direkte lenker, ukjentverdier og feilstater; typekontroll og produksjonsbygg; nettleserverifisering på desktop/mobil; deploy separat preview; test live API og basePath. Forutse at tokenets domenebegrensning kan kreve oppdatering etter tildelt deployadresse.
